- Feature importance analysis

# ▶️ How to Run

## 1 Clone the repository

```bash
git clone https://github.com/subashramalingam777-prog/Cognifyz-Internship
```

## 2 Install dependencies

```bash
pip install -r requirements.txt
```

## 3 Navigate to any task folder

Example

```bash
cd Task1_Restaurant_Rating_Prediction
```

## 4 Run the project

```bash
python task1_rating_prediction.py
```

Similarly,

```bash
python task3_cuisine_classification.py
```

```bash
python task4_location_analysis.py
```
